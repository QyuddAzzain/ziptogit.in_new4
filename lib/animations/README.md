# Kasirku animations

AOS 2.3.4 is vendored from the supplied `aos-2.zip` distribution.

- Runtime bundle: `aos.js`
- Styles: included in `app/globals.css`
- Initialization: `components/AosInit.tsx`
- No CDN or new npm dependency is required.

The animation layer is cosmetic. If the bundle fails to load, POS content remains visible and usable.
